You already use Git, but most people use about ten percent of it. This category lays
out a practical workflow — including how to undo things when they go wrong — then adds
the CLI and TUI that stop you bouncing to a browser, the three forges you can host
yourself when the code can't live on GitHub, and the hooks that protect review quality
without anyone having to remember.
