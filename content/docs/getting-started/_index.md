Knowing many tools matters far less than **having a few in your hands that you use
well**. Before the tool tours begin, this category covers getting an operating system
onto the machine at all, what to choose once it boots, how to install it, and how not to
lose your settings. Work through these four pages and every install command in the rest
of the site becomes copy-and-paste.
