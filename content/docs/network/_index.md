API work is a loop: construct the request precisely, read the response fast, repeat.
This category starts with `curl`, which exists on every machine you will ever SSH into,
moves to the friendlier HTTPie, covers request collections you can share with a team,
and ends with opening `localhost` to the internet for webhook testing.
