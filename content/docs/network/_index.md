카테고리는 어디에나 있는 `curl`부터 사람이 읽기 좋은 HTTPie, 팀과 공유 가능한
컬렉션 도구, 그리고 로컬 서버를 잠깐 외부에 열어주는 터널링까지 다룹니다.
