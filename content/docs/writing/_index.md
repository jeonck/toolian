Documentation is a time-saving device you send to your future self and your colleagues.
This category covers two note apps for accumulating personal knowledge — one built on
plain files, one open source with encrypted sync — the Markdown syntax that works
everywhere, diagrams you write as code, and a whiteboard for the sketches that refuse to
be formalised.
